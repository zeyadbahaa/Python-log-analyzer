# 🐍 Python Log Analyzer

A simple Python script that analyzes log files and counts different log levels.

This project was built as part of my **90-Day DevOps Challenge**, where I build and document a small project every day to improve my DevOps and automation skills.

## 🚀 Features

- Reads log files line by line
- Detects `INFO` messages
- Detects `WARNING` messages
- Detects `ERROR` messages
- Counts unknown log entries
- Displays a summary report

## 🛠️ Technologies

- Python 3
- Linux
- Bash / Terminal
- Git & GitHub
